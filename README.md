# 🚀 Project Boilerplates

This repository contains a collection of boilerplate templates for the tech stacks I often use, helping me quickly start new projects with common setups and best practices.

## 📁 Available Templates

- JavaScript + React + Tailwind CSS

## 💡 How to Use

- Clone the repo or copy the desired template folder.

- Customize it to fit your project needs.

- Start building!
