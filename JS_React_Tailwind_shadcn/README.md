# React + JavaScript + Tailwind CSS + shadcn/ui

This template was set up with:

- Node.js v22 (LTS)
- `pnpm` for package management
- Vite for build tool and dev server
- JavaScript
  - With ESLint
- React v19
- Tailwind CSS v4.1.5
  - Includes Prettier plugin for automatic class sorting
- [shadcn](https://ui.shadcn.com/) for component library

## How to use

```
pnpm install

pnpm dev
```

**Add shadcn components**

Run the following command to add the component into `src/components/ui`.

```shell
pnpm dlx shadcn@latest add <component_name>
```
